# DSA Practice

This repository contains my solutions to Data Structures and Algorithms (DSA) problems that I solve while practicing. The purpose is to track my progress, improve problem-solving skills, and keep all my solutions in one place.

## Repository Structure

Problems are organized by topic as I learn them.

```
DSA-Practice/
├── Arrays/
├── Strings/
├── Binary Search/
├── ...
└── README.md
```

## Solution Format

Each solution may include:
- Problem link
- Code
- Time Complexity
- Space Complexity
- Notes (when needed)
